# LabTrack: Property Inventory and Monitoring System Using QR Code

LabTrack is a web-based property inventory and monitoring system developed for 
laboratory equipment borrowing at Don Jose Ecleo Memorial College. It replaces manual, 
insecure borrowing processes with a QR-code-based workflow that tracks equipment, 
borrowers, and transaction history in real time.

## Features

- **QR Code Borrowing** — Borrowers scan a QR code on each piece of equipment to 
  initiate a borrow request via mobile phone.
- **Role-Based Access** — Separate views and permissions for Property Custodian, 
  Laboratory In-Charge, and Borrowers.
- **Transaction Management** — Borrow requests, approvals, returns, and condition 
  remarks (good, damaged, lost) are tracked per item.
- **Inventory Reporting** — Generates printable inventory reports filterable by 
  status, month, and year.
- **Responsive Interface** — Works across desktop and mobile devices for both 
  admin and borrower use.

## Tech Stack

- **Frontend:** HTML, CSS (Bootstrap), JavaScript (jQuery, html5-qrcode)
- **Backend:** PHP
- **Database:** MySQL
- **Server:** Apache (LAN deployment)

## Project Background

LabTrack was developed as a capstone project for the Bachelor of Science in 
Information Technology program at Don Jose Ecleo Memorial College (2024). It was 
built using the Rapid Application Development (RAD) methodology and evaluated 
against ISO/IEC 25000 software quality standards, receiving an overall "Agree" 
rating (mean score of 4.03) across functionality, reliability, usability, efficiency, 
maintainability, portability, compatibility, and security.
